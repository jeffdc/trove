The rewrite's legacy migration layer (docs/migration-matrix.md on branch go-ocaml-rewrite, and ocaml/migration/legacy_db*.ml in the uncommitted reshape) is written against Python schema version 2: tables `libraries`, `entries`, `files`, `schema_version`. Main has moved past that, and the migration must read what the later versions add.

**Version 3 (on main since e5f11d1).** Migration #3 in src/trove/db.py adds a side table marking entries whose Finder Date Created has been stamped:

```sql
CREATE TABLE entries_creation_date_stamped (
    entry_id INTEGER PRIMARY KEY REFERENCES entries(id) ON DELETE CASCADE,
    stamped_at TEXT NOT NULL
);
```

The backfill (`trove fix-created-dates`) uses it to skip entries already processed on a repeat run, and the importer marks entries automatically when it stamps them on first import. Matter 905e's guidance for the rewrite: if the run-centric schema replaces the entries table, fold this marker into whatever per-file durable state replaces it (for example a `finder_creation_date_stamped_at` column on the new file or run record). Don't carry the side table forward: it only exists because adding a column to the legacy entries table felt heavier than a join.

**Version 4 (planned by import-recovery, plan Task 1).** Migration 4 adds `import_runs` (id, library_id → libraries ON DELETE CASCADE, canonical absolute source_root, mode `copy`|`initialize`, status `pending`|`running`|`failed`|`completed`, last_error, failed_at, created_at, updated_at, completed_at; a partial unique index allows one non-completed run per (library_id, source_root, mode)) and a nullable `files.import_run_id` foreign key with ON DELETE CASCADE. Existing unscoped rows stay NULL. New `files.status` value `failed` with a stable `error_message` such as `import_timeout:<stage>:<destination>`.

Done when the legacy migration reads v2, v3 and v4 source databases, carries the stamped marker into the target schema's per-file state, and maps v4 run state (or reports it as an anomaly) instead of failing or ignoring it.
